# Android-стенд 0.1

LT/RT: добавлены аналоговые LTRIGGER/RTRIGGER с альтернативами BRAKE/GAS,
нормализация по диапазонам InputDevice в 0..1 и цифровой fallback L2/R2.
При наличии аналоговой оси дублирующее событие L2/R2 не округляет давление до 1.
В диагностике отображаются LT/RT; порог цифрового действия — 0.1.
Проверки нормализации, отпускания, одновременных кнопок и паузы прошли на JVM.
Реальные плавные нажатия LT/RT ещё ожидают пользовательской проверки.

Импорт/экспорт проверены на TB322FC через системный файловый диалог:
реальный PC-save 9 134 256 байт, SHA256
`16d2025ff8abab003b16bc90a454a2eb74ab2a37583492ed1bd91b408d640326`.
Совпали хеши исходного файла, приватной копии приложения и экспорта в
Download/MEResearch/mirrors-edge-pc-save.dat. Исходный Windows-save не изменён.
Сама загрузка прогресса не тестировалась. В Download/MEResearch также оставлена
тестовая входная копия pc-save-test.dat; эти файлы не включены в репозиторий.
Крестовину Bluetooth-контроллера пользователь подтвердил на устройстве.

Крестовина обрабатывается и через KEYCODE_DPAD_*, и через AXIS_HAT_X/Y.
HAT и цифровые кнопки хранятся отдельно, чтобы отпускание оси не сбрасывало
одновременно зажатую A/B и т. п. В диагностике выводятся имена кнопок и стрелки.
У подключённого Bluetooth-контроллера обнаружены ABS_HAT0X/Y. Тесты направлений,
диагонали, нейтрали и сочетания с A прошли; физические нажатия после обновления
должен подтвердить пользователь.

Добавлены обнаружение физической алфавитной клавиатуры и мыши, скрытие экранной
раскладки при любом внешнем источнике и пауза/сброс при отключении. Системные
кнопки громкости и виртуальная клавиатура не считаются игровой клавиатурой.
WASD — оси; Space/Ctrl/E/R/Q/Shift/Tab — A/B/X/Y/LB/RB/Back для диагностики.
Это предварительная привязка, а не подтверждённое управление всей игрой.
Клик в тестовую область захватывает мышь, Esc или средняя кнопка освобождают её
с паузой; левая/правая кнопки дают RT/LT. Относительные дельты камеры пока только
отображаются и сбрасываются через 100 мс, игрового потребителя ввода нет.
Мёртвая зона стиков не применяется к мыши. Настройка чувствительности и
переназначение ещё не реализованы. Одновременная игра стиком и WASD не арбитрируется:
оси получает последнее событие источника.

Тест модели покрывает все восемь сочетаний наличия pad/keyboard/mouse и переходы
с потерей одного/последнего устройства. Обновлённый APK установлен на TB322FC,
без внешних устройств кнопки видны и JNI PASS. Физическое подключение
клавиатуры/мыши и pointer capture ещё не проверены.

API: https://developer.android.com/reference/android/view/InputDevice
и https://developer.android.com/develop/ui/views/touch-and-input/gestures/movement#pointer-capture

Экранная раскладка обновлена по схеме Xbox 360: асимметричные стики, крестовина,
цветной ромб ABXY, LB/RB/LT/RT, Back/Start. Start переключает паузу. Физические
A/B/X/Y, бамперы, цифровые L2/R2 и D-pad соответствуют виртуальным кодам.
Аналоговые trigger axes ещё не обрабатываются. Коды кнопок не являются
подтверждённой финальной привязкой действий Mirror's Edge.
Обновление установлено через ADB на TB322FC; JNI PASS, отступы и отсутствие
обрезания кнопок проверены по снимку. Тактильное удобство требует оценки пользователя.

Собирается вручную официальными JDK/SDK/NDK без Gradle и сторонних Java-зависимостей.
Это диагностическое приложение, не порт и не запускатель PC EXE.
Идентификатор: `org.mirrorsedge.research`. ABI: только `arm64-v8a`. min API 26,
target API 35. APK подписан локальным отладочным ключом, не предназначен для публикации.

## Что реализовано в исходниках

- Проверка загрузки ARM64 JNI-библиотеки и арифметического вызова.
- Отображение модели, версии Android и ABI.
- Обнаружение контроллеров, два аналоговых стика, A/B/X/R1, Start для паузы.
- Экранные стики и четыре кнопки с pointer ID для multitouch.
- Автоматическое скрытие сенсорных элементов при контроллере, ручной override.
- Очистка ввода при смене устройства/потере фокуса и пауза при отключении.
- Сохраняемая галочка заставки. Она пока не влияет на игру: игрового запуска нет.
- Выбор файла через Android Storage Access Framework, ограниченная копия до 16 МиБ
  в приватное хранилище, предыдущая копия и атомарная замена. Экспорт байт обратно.
  Формат сохранения не проверяется и прогресс не загружается; UI явно сообщает это.
  Любой непустой файл в лимите принимается как тестовая копия, не как валидный save.

Пока нет: игры, графического backend, физики, пользовательского переназначения,
настройки размера/позиции/прозрачности кнопок, триггеров и проверки всех раскладок
контроллеров. Меню не оптимизировано для навигации только геймпадом. Элементы ввода
показывают числовое состояние, а не управляют персонажем.

## Сборка

```powershell
./build.ps1 -Jdk 'PATH_TO_JDK21' -Sdk 'PATH_TO_ANDROID_SDK' -Ndk 'PATH_TO_NDK30' -KeyStore 'PATH_TO_DEBUG_KEYSTORE'
```

SDK packages: `platforms;android-35`, `build-tools;35.0.0`, `platform-tools`.
Скрипт создаёт отладочный ключ при отсутствии (стандартный пароль android),
проверяет подпись APK и zipalign с 16-КиБ выравниванием несжатой библиотеки.
Ключ хранить вне Git; для повторной установки поверх использовать тот же ключ.

## Проверки на ПК

`tests/InputStateTest.java`: переходы hotplug/pause/resume и оси/mёртвая зона.
`verify_apk.py --ndk PATH`: ZIP, наличие JNI-символа и 164 арифметических проверки
скомпилированной ARM64-функции в Unicorn. Это не проверка JNI на Android.
Результаты в `../android-verification.json`. UI и операции SAF пока не проверены
на устройстве; автоматической проверки внешнего вида нет.

## Проверка на Y700

1. Включить USB-отладку, подключить кабелем передачи данных и разрешить этот ПК
   в системном запросе на планшете. `adb devices -l` должен показать статус device.
2. Установка: `adb install -r ../RunnerRecompiled.apk`.
3. Запуск: `adb shell am start -n org.mirrorsedge.research/.MainActivity`.
4. Проверить JNI PASS, несколько одновременных касаний, стики/кнопки геймпада,
   его отключение и паузу. После возврата фокуса нажать «Продолжить тест».
5. Выбрать копию PC-save, экспортировать и сравнить SHA256 на ПК. Ни исходный
   Windows-save, ни его имя внутри PC-игры приложение не меняет.

Во время подготовки ADB не обнаружил подключённых устройств. Установка и запуск
APK не выполнялись. Предварительный размер и подпись не доказывают работу на Y700.
