# Первый проход рекомпиляции — 21.10.2026

Получен C++ из пользовательского default.xex через собранный из исходников XenonRecomp. Это промежуточный вывод с известными ошибками семантики, не готовая игра.

## Результат

- XenonRecomp commit ddd128bcca99fe8bfbb99bea583c972351fa6ace, все submodules на закреплённых ревизиях.
- XenonAnalyse создал 424 описания таблиц переходов до последующей блокировки его EXE Defender. Повторный запуск заблокирован; настройки защиты не менялись.
- XenonRecomp выполнил первый проход до конца, exit 0. Этот exit не означает отсутствие ошибок — инструмент печатает их в журнал.
- 314 сгенерированных файлов, 238 019 476 байт, 79 611 объявлений функций. Автоматическое выделение функций не проверено на корректность; количество не является числом доказанно восстановленных игровых функций.
- Все 310 ppc_recomp.*.cpp прошли NDK Clang syntax-only для aarch64-linux-android35, SIMDe native aliases. Первый файл также скомпилирован в настоящий ARM64 .o. Полная объектная сборка и архивирование отражаются отдельно в arm64-build-result.json.
- Файлы получены из пользовательской игры и хранятся только в work/xbox-game-private/generated, не включены в проектный Git или APK.

## Ошибки первого прохода

| Категория | Число сообщений |
|---|---:|
| Не заданы адреса register save/restore helpers | 8 |
| Таблица переходов выходит за выделенную функцию | 1233 (79 различных адресов switch) |
| Таблица переходов не найдена | 2 |
| Не реализована инструкция | 298 (11 типов) |

Типы: mulhd, frsqrte, vcfpuxws128, vpkuwus128, vpkuhus128, vsel128, vpkswss128, vandc, eqv, vnor, dcbst. Успешная компиляция не гарантирует их семантику: исходный генератор может вывести комментарий и диагностику, пропустив действие неизвестной инструкции. Присутствуют и debugtrap в иных неподдержанных случаях. Не запускать этот вывод как готовую игру и не считать эти места безопасными заглушками.

Предупреждение заголовка ppc_context.h: 32-битный операнд inline asm при записи ARM64 FPCR; в массовой проверке предупреждение подавлено только для сокращения журнала, код не исправлялся. Перед проверкой численной семантики привести операнд к нужной ширине.

## Воспроизведение

Сборка host tools: CMake 4.4.4, Ninja, официальный LLVM-MinGW 20261006 (Clang 23.1.3). SHA256 ZIP LLVM: 317492c456aa27ee607a5919f1d2d38dcdc1112516a24d0bf4b00d078f52d17a. CMake flags: CMAKE_POLICY_VERSION_MINIMUM=3.5; CMAKE_CXX_FLAGS=-include cstdlib (старый fmt требует явного объявления malloc/free с этой версией libc++). Targets XenonRecomp и XenonAnalyse. Исходники генератора не менялись.

```text
XenonAnalyse.exe work/xbox-game-private/default.xex work/xbox-game-private/switches.toml
XenonRecomp.exe work/xbox-game-private/mirrors-edge.toml work/references/XenonRecomp/XenonUtils/ppc_context.h
```

Пример TOML здесь хранит пути относительно рабочей папки XEX, а не папки этого отчёта. Не запускать пример из xbox/ без корректировки путей. Локальные Python-скрипты tools/check_xbox_generated_local.py и tools/build_xbox_generated_local.py запускаются из корня рабочей папки чата и используют существующую структуру work/. В проект они сохранены для воспроизведения текущего эксперимента, не как универсальный SDK.

Официальный ZIP RexGlue 0.10.0 был заблокирован Defender как Trojan:Win32/Suschil!rfn до проверки SHA256; он не запускался. Собранный XenonAnalyse позднее заблокирован как Trojan:Win32/Bearfoos.A!ml. Это зафиксированные срабатывания, а не установленный анализом факт вредоносности или ложного срабатывания. Защита не отключалась, исключения не добавлялись. Отдельный XenonRecomp запустился штатно.

## Следующий проход

Сначала определить адреса save/restore helpers и исправить 79 границ switch-функций; затем добавить недостающие инструкции с проверкой семантики. Графика, звук, ядро Xbox и среда исполнения пока не связаны с выводом. Подключение к RexGlue потребует согласования его генераторного ABI; одинаковый C++-формат сам по себе не гарантирует совместимость XenonRecomp и RexGlue.

## Объектная сборка завершена

Все 311 единиц C++ (310 с функциями и таблица mappings) скомпилированы NDK для Android ARM64, -O0 -fPIC, за 39,5 секунды. Получено 150 111 720 байт объектных файлов. llvm-ar создал work/xbox-game-private/libmirrorsedge_ppc_draft.a размером 154 979 982 байта. Это настоящий архив ARM64-кода, но он сохраняет все перечисленные ошибки генерации; линковка с runtime, запуск и проверка эквивалентности не выполнены. Сводка: arm64-build-result.json.
