# GPU-readback экспозиции — 22 октября 2026

Режим ME_DIAGNOSTIC_EXPOSURE_READBACK=1 добавлен через prepare_exposure_readback.py. Зависит от существующего draw trace (draw_ps_hash). В конце draw PS80C8053F5C552351 читает максимум8 образцов по16байт из VulkanSharedMemory, выбранных по фактическому fetch1 (1×1). Перед копированием shared memory переводится в read usage, барьеры публикуются; staging buffer transfer→host, AwaitAllQueueOperationsCompletion, vkMapMemory, invalidate для non-coherent. После чтения staging buffer освобождается. Никаких записей в guest memory, принудительной экспозиции или изменения текстуры. Режим синхронный, замедляет diagnostic draw и не предназначен для замера производительности. По умолчанию выключен.

## Реальные данные

1600 →704 →576 →512 →512 →512 →512 →512.

Пример bytes0200020002000200: endian swap даёт u16=512. В unsigned UNORM это512/65535≈0.00781262, после множителя64 из итогового PS≈0.5000076. Первый образец1600 даёт≈1.56252. Это совместимо с меняющейся и затем стабилизировавшейся экспозицией. Это чтение resolved shared-buffer bytes, не численное чтение результата texture filtering. Полная корректность HDR и экспозиции этим не доказана, но нулевой/необновляющийся буфер в этих образцах не наблюдается.
