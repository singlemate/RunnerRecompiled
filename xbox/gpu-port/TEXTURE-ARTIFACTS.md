## Сравнительный запуск

Добавлен только диагностический opt-in ME_TEXTURE_RGBA_DIAGNOSTIC=1. Он направляет BC1/2/3/4/5 через существующие SDK compute decode fallback pipelines, независимо от native format capability; настройки гаммы/игровых шейдеров/ресурсов не меняет. Без переменной остаётся исходный выбор форматов. Это эксперимент, не исправление и не настройка для пользователя.
