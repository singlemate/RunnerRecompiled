# Изоляция цвета одного PS — 22 октября 2026

`prepare_shader_probe.py` идемпотентно добавляет opt-in диагностику в StoreResult SPIR-V translator. Только PS 5EBE814012217F48, output color0:

- ME_DIAGNOSTIC_PS_INPUT6=1 — пишет RGB входного interpolator6 напрямую, alpha1.
- ME_DIAGNOSTIC_PS_INPUT6=2 — пишет постоянный RGB(0.25,0,0.25), alpha1.
- Без переменной исходный shader output не изменяется. Это намеренное искажение только для локализации, не исправление.

Скрипт компилирует одну TU в pipeline_shader_spirv_translator.cpp.o. Затем нужен обычный startup/build.ps1. Флаг учитывается при трансляции; сравнивать отдельными процессами, не менять окружение внутри одного shader cache.
