## Диагностическое исключение одного шейдера

ME_DIAGNOSTIC_SKIP_PS/ME_DIAGNOSTIC_SKIP_VS принимают только16символов hex hash; без переменных ничего не пропускается. Отключённый draw явно логируется external_diagnostic_draw_omitted/not_a_fix=true. Это изменение изображения только для изоляции причины, не обход для рабочей сборки.

draw-ablation-self-test.log:641checks/exit0. draw-ablation-game.log:65секунд/timeout124; выбран PS5EBE814012217F48,2112indices, без textures. При его исключении исчезает светлый фон неба, появляется чёрное небо; ближний город/UI остаются. Снимок work/startup/draw-ablation-frame.png визуально проверен. Этот опыт не доказывает, что shader вызывает отдельные пятна: при чёрном небе нельзя оценить их отдельно. Отключение не принято как исправление.

Следующий эксперимент: depth-only VS3DABEAE3153908FC,24indices при первом наблюдении, color mask0, raw depth00700766 (z_enable/z_write_enable, greater-or-equal). depth-ablation-game.log:65с/timeout124; данный VS встречается также с6indices, то есть исключение не ограничено только одним draw. Визуальная проверка work/startup/depth-ablation-frame.png подтверждает сохранение тёмных дальних силуэтов. Гипотеза об устранении дефекта исключением этого depth-прохода не подтвердилась; пропуск не принят в рабочее поведение.

## Шейдер и константы

Опциональный ME_DIAGNOSTIC_DUMP_SHADER сохраняет дизассемблированные VS/PS выбранного фонового прохода и256pixel float constants только в /data/local/tmp. Получены приватные work/startup/background-vs.txt, background-ps.txt и background-all-constants.txt. background-shader-game.log/background-constants-game.log завершены внешним35сtimeout124 без изменения рендера; skip PS/VS переменные в этих запусках отсутствовали.

PS5EBE814012217F48 не использует texture fetch. Он обрабатывает интерполированный цвет, использует c253..c255 и c0; это не доказательство корректности всего прохода или его ответственности за отдельные силуэты. Проверено, что c0=8, старшие константы не нулевые. VS получает цвета/данные из vertex fetch и пишет интерполяторы. Дизассемблирование и сами игровые данные остаются в приватной work-папке.
