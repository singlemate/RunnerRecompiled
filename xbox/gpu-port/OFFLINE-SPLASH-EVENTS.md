# Offline startup, локализация и события

Проверено на Y700 Gen4 / test device, 2026-10-21.

XNetStartup и WSAStartup в диагностическом режиме возвращают недоступность подсистемы (10091). Хостовые сокеты не создаются. Игра обработала отказ и продолжила. Неверные XNet-параметры возвращают 10022; полная Xbox-сетевая семантика не реализована.

Английский language profile позволил игре прочитать Coalesced.int (424640 байт), затем Splash.bmp (2764856 байт) из собственной Xbox-копии. Большие NtReadFile-буферы проверяются по всему диапазону committed-страниц. Игровые данные остаются в work/ и на устройстве.

MmQueryAddressProtect поддерживает отслеживаемые VM-регионы: committed RW=4, decommitted=1. Иные области останавливаются диагностикой.

Реальный helper 82A012E8 задаёт root FFFFFFFC и attributes 80. Поддержано отдельное внутреннее пространство имён для этого root и OPENIF. Повторное открытие события сохраняет общий объект, его тип и состояние; последнее закрытие уничтожает объект. Полный Object Manager не реализован.

Игра прошла прежнюю остановку NtCreateEvent и создала дополнительные потоки. Прогон остановлен внутренним alarm(20), signal 14. Это диагностический лимит, а не доказанный memory fault. Последний LR 8238E858 относится к функции 8238E850, но не доказывает текущую инструкцию или причину ожидания.

Проверки: 352/352 на планшете, включая named-event lifecycle, большой буфер с decommit-дырой, защиту соседних страниц и отказ offline startup. Логи: device-named-event-self-test.log и device-named-event-explore.log. Последняя пересборка после игрового прогона добавила только self-tests.

Далее: получить точный снимок исполняющегося кода/потока при лимите и отделить долгую работу от ожидания. Сохранения, непрерывное аудио и Android presentation остаются открытыми задачами.
