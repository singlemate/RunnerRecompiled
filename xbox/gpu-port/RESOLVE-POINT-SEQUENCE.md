# Последовательные образцы HDR после resolve — 22 октября 2026

prepare_resolve_point.py добавляет ME_DIAGNOSTIC_RESOLVE_POINT=<8hex>, optional ME_DIAGNOSTIC_RESOLVE_CONTROL=<8hex>. Адреса задаются явно для текущего диагностического размещения; это не постоянные адреса игры. В стандартном пути IssueCopy после успешного Resolve, если written range пересекает точку, выполняется bounded staging readback8байт либо2×8байт с control. Максимум16 успешных образцов; GPU-fence completion и invalidate non-coherent. Нет guest writes, изменения цвета или Activity. По умолчанию выключено. Синхронизация меняет тайминги, не использовать для FPS.
