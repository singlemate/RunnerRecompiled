# Проверка CPU cache line

2026-10-22. После добавления NT multiple wait для mutants.

Предыдущий игровой прогон завершился по диагностическому лимиту240с. Worker61091000 проходил разные участки82EB/82EC, а многие снимки host PC попадали в word_writable. Это указатель на горячую проверку, не доказательство deadlock или завершения декодирования.

Диагностический dcbst прежде искал содержащую128-байтовую линию VM-область, затем вызывал checked_span:32поиска word_writable. Теперь MeVirtualMemory::committed_cache_line проверяет принадлежность целой линии текущей области и committed-бит соответствующей страницы. Линия выровнена на128байт, поддерживаемые guest pages4096/65536байт также выровнены; линия не пересекает страницу. Нет сохранённого Region* или положительного cache, поэтому decommit/free учитываются при следующем вызове. Обычные проверки других imports не изменены.

Сохранены ограничение диагностического режима, отказ для неподдержанной памяти и seq_cst fence. Это по-прежнему только coherent CPU VM, не реализация cache flush для GPU/device memory и не синтез GPU completion.
