# Второй проход рекомпиляции — 21.10.2026

Исправлен локальный генератор XenonRecomp, повторно переведён тот же базовый XEX. Все 312 единиц C++ собраны NDK r30 для Android ARM64 (-O0 -fPIC); ошибок компиляции нет. Создан текущий work/xbox-game-private/libmirrorsedge_ppc_draft.a (158 574 126 байт). Игра не запускалась, runtime не связан.

## Изменения и проверка

1. Найдены восемь register save/restore helpers. У каждого единственное совпадение, проверены все инструкции последовательного сохранения/восстановления и завершающий blr, а не только сигнатура первого слова. Адреса и длины проверок: register-helpers.json.
2. Поддержаны vandc, vnor и eqv — 190 встреченных инструкций. Их фактически сгенерированные выражения прошли 19 000 проверок относительно независимых побитовых таблиц истинности, включая совпадения регистров источника/назначения. Выполнение кандидата — Windows x64; это не проверка на PowerPC-железе или планшете. EQV record-form флаги отдельно не проверялись.
3. Исправлена граница функции 0x8223A5D8, размер 0xDC. Просмотрена последовательность кода, ветви switch и выходы blr. Полученный C++ сравнен с исходными PPC32 big-endian инструкциями в Unicorn на 7770 комбинациях месяца/года/дня. Возвращаемый r3 совпал; полное состояние и ARM64-исполнение не проверены.
4. Исправлена ширина операнда записи ARM64 FPCR (uint64_t). Повторная сборка включает -Werror=asm-operand-widths, прежнее предупреждение не подавляется.
5. Неизвестные инструкции, неразрешённые прямые вызовы и выходы switch за функцию теперь генерируют явную остановку (__builtin_trap). Ранее такие пути могли молча пропустить действие/вернуться. Это фиксация нерешённой семантики, не её реализация.

Дополнительно обнаружены 238 мест неразрешённых прямых вызовов: прежде они оставляли лишь комментарий в C++. Во втором проходе они явно диагностируются. Их нельзя считать новыми ошибками, возникшими из-за правок, или скрывать успешной компиляцией.

Остались 8 типов инструкций: mulhd (1), frsqrte (3), vcfpuxws128 (31), vpkuwus128 (31), vpkuhus128 (31), vsel128 (8), vpkswss128 (2), dcbst (1). Следующая работа — расширение анализа CFG с учётом switch и реализация оставшихся инструкций с проверкой семантики. Границы остальных функций не растягивались автоматически до максимальной метки: такой приём может соединить разные функции и скрыть ошибки.

## Воспроизведение и ограничения

Патч относительно ddd128bcca99fe8bfbb99bea583c972351fa6ace: xenonrecomp-local.patch. Конфигурация: second-pass-config.example.toml (пути относительно рабочей папки с XEX). Полные журналы и сводки: codegen-second.log, codegen-second-result.json, arm64-build-second-result.json, bitwise-test.json, date-function-test.json.

Патч дополнительно содержит необязательный диагностический экспорт секций через ME_RECOMP_IMAGE_DUMP. Он использован только для анализа локальных байтов пользователя, не нужен для обычной генерации; исходный XEX не меняется. Неуспешный экспорт .reloc не использовался. Файлы секций/игровой C++ не включены в проектный Git или APK.

Скрипты test_xbox_date_local.py и test_xbox_bitwise_local.py рассчитаны на существующее дерево work/ этого чата, выполняются из его корня. Тест функции даты читает локальную .rdata и резервирует 4 ГиБ виртуального адресного пространства, коммитит лишь нужные страницы. Это диагностическая модель guest-адресов для проверки функции, не Android runtime.
