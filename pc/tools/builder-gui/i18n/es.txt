README	Mirror's Edge para Android, preparado a partir de tu copia del juego\n\nEn esta carpeta:\n  RunnerRecompiled-pc-personal.apk  la aplicación\n  MirrorsEdge-GOG.zip               los archivos de tu juego\n\nQué hacer:\n1. Copia el APK y MirrorsEdge-GOG.zip a tu tableta, por ejemplo en Download.\n2. Instala el APK. Android pedirá permitir la instalación desde este origen.\n3. Abre la aplicación y elige MirrorsEdge-GOG.zip cuando pida el archivo del juego.\n4. Si el juego no se inicia o la imagen tiene fallos, abre Controlador gráfico en los ajustes y elige un paquete ZIP de controlador para AdrenoTools (por ejemplo, Turnip).\n\nNecesitas un dispositivo Android con Vulkan y una CPU ARMv8.4 o más reciente.\n\nEl APK y el archivo contienen datos de tu copia con licencia. Guárdalos para ti: no los publiques ni los compartas.\n
