# Требования к сохранениям, драйверам и внешнему тесту

2026-10-21. Направление Xbox360 → Android ARM64. Эти пункты обязательны для тестовой сборки, но пока не реализованы в гостевом файловом runtime.

## Сохранения Xbox-версии — до внешнего теста
- Постоянный корень сохранений отдельно от игровых ресурсов, настроек, драйверов и shader cache. Очистка кэша, повторная установка ресурсов и смена драйвера не затрагивают сохранения.
- Стабильный гостевой профиль/идентификатор пользователя и стабильное сопоставление путей Xbox storage/content: один и тот же прогресс должен находиться при каждом запуске. Профиль не генерируется заново по времени/версии/APK.
- Нельзя возвращать гостевой SUCCESS до фактического успешного write/flush/close. Disk-full, permission и I/O ошибки должны доходить до игры. Формат сохранений не подменяется нашей заглушкой.
- Сохранить файловую семантику игры. Для резервного копирования использовать согласованный снимок после завершения записи: временный файл, синхронизация данных, атомарная фиксация manifest/snapshot и синхронизация каталога где поддерживается; предыдущее исправное поколение не удалять до проверки нового. Нельзя автоматически менять временные/rename операции самой игры без анализа её протокола.
- Резервные копии с несколькими поколениями, версия формата backup, размеры/хеши и проверка перед восстановлением. При повреждении не затирать последний исправный backup и не сбрасывать прогресс молча.
- Экспорт/импорт Xbox-сохранений через системный файловый диалог. Пользовательская копия вне app-specific storage необходима для переноса и сохранности при удалении приложения/очистке данных. Эти операции Android могут удалять внутренние данные; абсолютная гарантия без внешней копии невозможна.
- Один package id и сохранённый ключ подписи для обновлений. Отдельный diagnostic package не должен выдавать свои пути за игровое хранилище. Не просить тестера удалять приложение ради обновления без экспорта копии.

Проверки до объявления поддержки: создание прогресса → загрузка, force-stop → запуск, перезагрузка устройства, обновление подписанного APK поверх, очистка shader cache, переустановка ресурсов, смена драйвера. Дополнительно: прерывание записи, нехватка места, повреждённый snapshot, восстановление backup, экспорт → удаление приложения → установка → импорт → загрузка. Измерять не только наличие файлов/хеши, но и фактическую загрузку игрового прогресса. Ни одна из этих игровых проверок пока не выполнена.

## Драйверы
Изучен образец LibertyRecompAndroid: system/bundled/custom driver, import ZIP, per-app загрузка через AdrenoTools, логирование фактически выбранного драйвера и fallback. Использовать как архитектурный reference, не как замену Mirror’s Edge runtime; перед переносом кода проверить лицензии и зафиксировать версию. Библиотеки не скачаны и не подключены в этом этапе.

В нашем текущем SDK VulkanInstance::Create загружает стандартный Vulkan loader через Library::Load. Для custom-драйвера нужна интеграция до создания instance/device: согласованный resolver vkGetInstanceProcAddr, lifetime библиотеки, маршрутизация всех Vulkan function pointers через выбранный loader. Один импорт .so или env.txt не является реализацией.

План: system driver как исходный вариант, пользовательский ZIP как опция. Проверять ABI arm64, meta/libraryName, непересечение путей при распаковке, пределы размера и принадлежность выбранной .so импортированному пакету. Смена только с перезапуском игрового процесса; callback/device старого драйвера нельзя смешивать с новым. При ошибке загрузки допускается запуск нового процесса с system driver, причина видима в отчёте. Не гарантировать fallback после driver crash в том же процессе. ОС-драйвер не заменять.

Shader cache разделить по версии runtime, GPU/device/vendor/driver и pipeline cache UUID. Переключение драйвера не изменяет saves. Выбор готовой версии Turnip — после feature probe на конкретных устройствах, не по одному названию GPU.

## Матрица внешнего теста
| Устройство | Данные | Статус |
|---|---|---|
| Lenovo Y700 Gen4 | TB322FC, фактически исследованный Adreno830 | 278 runtime self-tests; ранний запуск AOT через ADB, ещё не игровая сборка |
| Samsung Galaxy Z Fold6 | По данным пользователя: Snapdragon8Gen3 for Galaxy, Adreno750 | Не подключён и не проверен; характеристики/прошивку/Vulkan limits снять самим приложением |

Для Fold6 обязательно проверить real OS/API, Vulkan features/extensions/limits, CPU host page size (не предполагать4096), доступную память, audio buffer format, внешний/внутренний экран, изменение размера и сворачивание. Текущий native memory probe явно требует страницы4096 для physical aliases: 16KiB устройство до адаптации должно получить понятное сообщение, а не обещание совместимости. APK alignment16KiB сам по себе не исправляет это ограничение runtime.

Пакет тестера: APK одной подписи, build id, инструкция по пользовательским файлам игры и backup, экспорт диагностического отчёта (model/API/GPU/driver/page size/последний этап/ошибка). Не включать игру, пользовательские сохранения и ключ подписи. Перед отправкой проверять установку/обновление, экспорт/восстановление и запуск на Y700. Тестеру не пишем и ничего не отправляем автоматически.
